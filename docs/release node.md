### **版本说明 / Version Information**

1. **当前版本为 Beta 测试版，功能仍在持续迭代中，可能存在不稳定情况。**  
   **This is a Beta test version. Features are still under active development and may be unstable.**

2. **当前仅支持 SSH 协议；如使用 Telnet，将会触发错误提示。**  
   **Currently, only the SSH protocol is supported. Using Telnet will trigger an error.**

3. **巡检命令库基于社区数据库构建，仍在不断完善中：**  
   **The inspection command library is built from a community-maintained database and is still being improved:**  
   - **华为（Huawei）设备命令支持较为完善；**  
     **Huawei device command support is relatively complete;**  
   - **其他厂商命令正在持续补充与优化中。**  
     **Commands for other vendors are being continuously expanded and refined.**
